# Projek: Pesanan YB ADUN Ampangan (Jom Daftar ePBMY)

Fail HyperFrames untuk video `videos/YB_Ampangan_JomDaftar_Reels.mp4` (gaya v3, warna maroon/emas kempen "Jom Daftar").
Fail media (rakaman, gambar, muzik) tidak disimpan di sini kerana saiznya besar; letakkan semula dalam `assets/` untuk edit.

- `tools/cut2.py`: cantum 2 bahagian ucapan, buang senarai parti dan jeda panjang, besarkan ke 1080x1920.
- `tools/captions_yb.py`: sari kata dengan ejaan dibetulkan (dikunjungi, Gen Z, ePBMY, menceburkan).
- Suara YB dikuatkan dengan `loudnorm=I=-16:TP=-1.5` kerana rakaman asal -28 LUFS.
